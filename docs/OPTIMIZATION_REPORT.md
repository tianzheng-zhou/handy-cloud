# Handy Cloud 优化交付记录

验证日期：2026-09-18。实现按三个阶段提交，前两个阶段分别为 `61d6eaf`（品牌与迁移）、`d1b88d7`（核心链路与设置）；第三阶段包含此报告。

## 已完成的改动

1. **独立品牌与迁移**：产品 Handy Cloud、标识 `com.tianzhengzhou.handy-cloud`、可执行文件 `handy-cloud`；窗口、托盘、项目入口及安装配置同步。首次启动在设置/历史初始化前复制原版数据，通过 SQLite 备份处理 WAL，使用私有暂存目录、锁和完成标记，支持中断重试、不覆盖新数据。保留原目录与便携 `Data`，不迁移屏幕授权 token。更新能力由只读命令统一控制，默认手动下载安装，删除上游更新源与发布者签名配置。
2. **核心链路**：删除 StreamRouter、空录音回调、流式 VAD/悬浮窗、本地模型与 GPU/卸载设置及命令。设置 schema 升为 2，保留有效配置；没有云端 Key 的旧用户重新配置 Key。按字节解析 SSE，正确拼接 UTF-8/CRLF/多行事件，识别结束、服务端错误和异常截断；复用 HTTP 客户端并逐请求认证。取消会丢弃请求并阻止后处理/粘贴。WAV 后台编码一次，同一字节用于保存和上传；保存失败继续转写并提示，跳过缺音频的历史条目。
3. **设置与前端**：后端在锁内读改写并传播保存错误、回滚内存缓存；系统操作在锁外。前端统一检查 Tauri Result、按字段/相关设置组排队、仅回滚失败字段，保护正在保存的数据免受旧刷新结果覆盖。后处理端点与模型重置、新提示词与选中状态在单个事务中保存。设置初始化共享一个任务；主窗口、侧栏、云端页及常用控件改用字段订阅。
4. **精简与工程**：设置页、发布说明渲染器和非英语语言按需加载。保留全部 24 种语言，中英文补齐；其他语言新增内容采用显式英文回退清单。删除失效本地模型介绍和旧发布说明；键、空值、插值变量严格检查。移除 8 个无引用的前端依赖，清除 Nix Vulkan/shaderc 依赖，同步 Bun/Nix 锁描述；Nix 补充带哈希的 VAD 资源。显式使用 TypeScript Vite 配置且类型检查不产生副本。重写使用、构建和贡献文档。

原云端模型与语音转写提示词保持不变。没有新增实时转写，没有自动重试可能计费的转写请求。保留原作者版权与贡献者致谢。

## 加载体积

单位为十进制 KB，原始 JS 与每个文件分别 gzip 后的大小。基线为实施前构建记录：主入口 486.34 KB + 共享包 879.12 KB；原首屏已预加载全部语言和设置页面。

当前使用 Vite manifest 遍历主入口、默认通用设置页的静态依赖，去重统计。中文另计其动态语言包，升级场景另计说明弹窗。未把全部按需文件误算为首屏，也未忽略默认页的动态依赖。

| 场景                     |     原始 JS |      gzip | 相比原始 JS 基线减少 |
| ------------------------ | ----------: | --------: | -------------------: |
| 原首屏基线               | 1,365.46 KB | 396.53 KB |                    — |
| 英文首屏（含默认设置页） |   395.99 KB | 131.90 KB |               71.00% |
| 中文首屏（含中文语言包） |   413.91 KB | 139.69 KB |               69.69% |
| 英文首屏 + 升级说明弹窗  |   560.04 KB | 182.50 KB |               58.98% |

执行 `bun run build && bun run check:bundle` 可复测；日常 CI 对英文和中文正常首屏执行“至少减少 30%”的预算检查。这是前端加载体积，不是各平台安装包体积；本轮没有完成各平台安装包大小对比。
