## Handy Cloud

Handy Cloud uses Alibaba Bailian (DashScope) Qwen Omni models for speech transcription.
Configure your API key in settings, then choose Qwen3.8-Omni Flash, Qwen3.5-Omni Flash or Plus.

- Existing Handy settings, history, recordings and custom sounds are copied on first launch when the new data directory is empty. The original data is retained.
- Screen context is optional and sends a screenshot with the audio. System permissions must be granted again for Handy Cloud.
- Cancelling stops the pending cloud request. Cancelled results are not pasted.
- Settings and languages load as needed. Failed settings writes restore the affected control and show an error.
- Updates are installed manually from [this project's releases](https://github.com/tianzheng-zhou/handy-cloud/releases).

Based on [Handy](https://github.com/cjpais/Handy), with thanks to its contributors.
